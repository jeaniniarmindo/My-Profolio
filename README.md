# Jeanini Soares — Portfolio

Live: https://jeaniniarmindo.github.io/

Built with [Astro](https://astro.build) (Node.js). Deployed automatically to GitHub Pages on every push to `main`.

## Edit content
All text (experience, skills, projects, research, contact, chat answers) lives in
[`src/data/profile.ts`](src/data/profile.ts). Edit it, commit, push — done.

## Run locally
```bash
npm install
npm run dev      # http://localhost:4321/
npm run build    # production build into dist/
```
